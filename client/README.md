# Dimewise — Client

React SPA for the Dimewise household budgeting application.

## Tech Stack

| Concern | Technology |
|---------|-----------|
| Framework | React 19 + Vite 7 |
| Language | TypeScript (strict) |
| UI Library | Ant Design 6 |
| State / API | Redux Toolkit (RTK Query, auto-generated from OpenAPI) |
| Auth | Clerk (`@clerk/clerk-react`) |
| Routing | React Router 7 |
| Forms | Ant Design Form |
| Date Handling | Luxon + Day.js (date pickers) |
| Formatting | Biome |
| Package Manager | Bun |

## Getting Started

```bash
# Install dependencies
bun install

# Start dev server
bun run dev

# Regenerate API client from OpenAPI spec
bun run gen:openapi

# Type check
npx tsc --noEmit

# Lint & format
bun run check
```

## Environment Variables

Create a `.env.local` file:

```
VITE_CLERK_PUBLISHABLE_KEY=pk_test_...
VITE_API_BASE_URL=http://localhost:4000
```

## Project Structure

```
src/
├── assets/              # Static assets
├── components/          # Reusable components by feature
│   ├── Auth/            # AuthGuard
│   ├── Budget/          # BudgetCategoryModal, BudgetOverviewCard
│   ├── Expense/         # ExpenseModal
│   ├── Household/       # HouseholdDashboard
│   ├── Layout/          # AuthenticatedLayout, PublicLayout
│   └── Settlement/      # SettlementDetail
├── pages/               # Page-level components (one per route)
│   ├── BudgetsPage      # Budget category CRUD with overview
│   ├── DashboardPage    # Home dashboard with stats, recent activity
│   ├── ExpensesPage     # Expense list with filters & pagination
│   ├── SettlementsPage  # Settlement history & generation
│   └── ...              # Auth, household setup/settings pages
├── routes/              # Router config & route enum
├── store/               # Redux store + RTK Query
│   └── api/             # Auto-generated API layer (from OpenAPI)
├── types/               # Global type declarations
└── utils/               # Utility functions (currency formatting)
```

## Code Generation

The API client (`src/store/api/api.ts`) is auto-generated from the OpenAPI spec at `openapi/openapi.yml`. **Do not edit this file manually.** Run `bun run gen:openapi` after spec changes.
